---
description: Parallel verification with multiple hypotheses
argument-hint: PROBLEM="<problem statement>"
---

Use parallel verification to solve PROBLEM.

Phase 1: Diverge
- Generate 3-4 distinct hypotheses/approaches.
- Each should be testable and complete.

Phase 2: Explore
- For each hypothesis, fully work it through.
- Note strengths, weaknesses, and confidence (1-10).
- If other models are available, optionally query them for one hypothesis each.

Phase 3: Verify
- Cross-check for contradictions and edge cases.
- Identify where approaches agree.

Phase 4: Converge
- Present the winning approach and why it wins.
- Note pruned paths and remaining uncertainties.

Output:
- Winning solution, confidence, and key risks.
