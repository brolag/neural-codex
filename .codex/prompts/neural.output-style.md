Use the requested STYLE:
- default: standard response format.
- concise: terse bullets, no fluff.
- table: small markdown table with key columns only.
- yaml: structured YAML response.
- html: respond with a small HTML snippet.
- genui: UI-focused output (HTML/CSS with layout hints).
- code-first: show code/snippets first, then minimal notes.
- checklist: list tasks with [ ] and short detail.

Apply the style to the current response; keep it minimal.
