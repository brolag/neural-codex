DISCOVER_SPEC_CRAFT_VET

> Durable artifacts and independent gates for non-trivial changes_

$discover

Map knowns, unknowns, blindspots, and references into unknowns-map.md.

$spec

Lock signatures, invariants, dependencies, and executable acceptance in plan.md.

$craft

Capture the baseline, implement the approved plan, and measure the delta.

$vet

Review a neutral diff in fresh context and return SHIP or HOLD.

$exercise

Drive the real user flow and return evidence-backed PASS or FAIL.

$craft requires both review and behavioral evidence before the human ship decision. It never commits, pushes, merges, or deploys automatically.

Different command, preserved workflow: /prompts:neural.craft remains the legacy Context, Requirements, Actions, Flow, Tests YAML builder.
