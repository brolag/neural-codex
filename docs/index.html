Codex-native workflows for serious iteration.

neural-codex ports the neural-claude loop, prompts, and templates into the Codex CLI. It is lean, file-based, and designed for repeatable execution with clear state and logs.

Get started View on GitHub
What ships

Prompts, templates, loops, and skills

  • Ralph loop with PRD gating
  • Namespaced prompts for planning and routing
  • Templates for PRDs, progress logs, expertise
  • Skills for memory, worktrees, reviews, and learning

Why it works

File-based state

Every task, log, and plan lives in the repo for auditability.

Small-loop discipline

PRD-driven tasks keep the loop safe and measurable.

Prompt namespace

All workflow commands are under `neural.*` for clarity.
