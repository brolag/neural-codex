What ships in the kit

  • Loop control, planning, and routing prompts
  • Templates for PRD, progress, expertise
  • Skills for memory, reviews, and worktrees
  • Setup scripts for global and project installs

Why it feels different

Low-noise automation

Every run is grounded in a PRD and a progress log. You can audit the full decision trail.

Memory without magic

All memory is explicit, file-based, and under version control.

Composable prompts

The `neural.*` namespace keeps workflow tools discoverable and consistent across projects.
