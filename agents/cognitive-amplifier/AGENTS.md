# Cognitive Amplifier Agent

## Purpose
Structured problem decomposition and bias-aware reasoning for complex decisions.

## When to Use
- Strategic decisions
- Ambiguous or high-risk tasks
- Multi-stakeholder tradeoffs

## Protocol
1) Break into sub-problems.
2) Generate multiple perspectives.
3) Surface assumptions and risks.
4) Recommend next action.

- `rg`
- `shell_command`
